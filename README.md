# 📊 K-Means Clustering on Digits Dataset

This project demonstrates **K-Means clustering** on the famous `digits` dataset from `scikit-learn`, visualized using **PCA (2D projection)**.

---

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ml-kmeans-digits.git
   cd ml-kmeans-digits
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the script:
   ```bash
   python kmeans_digits.py
   ```

---

## 📈 Output
- The program applies **K-Means clustering (k=10)** on the digits dataset.  
- Results are plotted in **2D using PCA**.  
- Red crosses (`X`) show the **cluster centers**.
